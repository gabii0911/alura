🌌 Sobre o Projeto

NEXUS é um projeto de website com uma identidade visual inspirada em filmes futuristas e universos de ficção científica.

A proposta é criar uma experiência digital imersiva, com uma interface moderna, tecnológica e cinematográfica, transportando o usuário para um mundo onde inteligência artificial, tecnologia e humanidade se conectam.

🎨 Identidade Visual
🌃 Estética Cyberpunk e Sci-Fi.
💜 Tons de neon roxo, azul e ciano.
🌑 Fundo escuro com elementos luminosos.
✨ Animações futuristas e efeitos de transição.
🤖 Elementos visuais inspirados em inteligência artificial.
🔮 Interface minimalista e imersiva.
